pg8000.core.H_pack()¶

S.pack(v1, v2, …) -> bytes

Return a bytes object containing values v1, v2, … packed according to the format string S.format. See help(struct) for more on format strings.

pg8000.core.H_unpack(buffer, offset=0)¶

Return a tuple containing unpacked values.

Values are unpacked according to the format string Struct.format.

The buffer’s size in bytes, starting at position offset, must be at least Struct.size.

See help(struct) for more on format strings.
